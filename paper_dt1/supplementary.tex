\section*{S1. PureChain provenance deployment details}

Solidity 0.8.20 using \texttt{evmVersion: paris} and
\texttt{viaIR: true}, to target the pre-Shanghai Ethereum Virtual
Machine supported by PureChain, and deployed on the PureChain
mainnet (RPC endpoint \texttt{https://purechainnode.com}).
